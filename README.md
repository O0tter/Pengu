# Pengu · 像素写作工坊

**手头只有几百字、两三段样本文字时，能不能让 AI 生成更接近这些文字表达习惯的新文章？**

Pengu 围绕这个问题做短语料条件下的风格模拟。它从少量文字中提取句长、断句、用词等机械特征，再让模型构造一个“在它的文本关联体系中，最可能这样写的人”，将这个幕后写作者用于新的生成任务。

不用准备一位作者的完整作品，也不需要训练或微调模型。你提供短语料和新任务，通过四份大纲选择方向，再比较六篇候选正文，决定留下哪一版。

Pengu 将这套方法放进了一个本地运行的像素风工作台，支持中文科普、观点短文、杂文／散文，以及独立的英文写作流程。当前提供 macOS 源码启动包，需要自行配置模型 API。

## 为什么从短语料出发

只有几百字时，很多特征很难被确定为写作者的长期习惯。某段句子较长，可能因为题目复杂；情绪较低，也可能只是主题使然。单纯让模型总结“冷硬、克制、细腻”，容易只改变局部措辞，文章选择哪些材料、如何理解问题、怎样形成判断，仍然沿用模型熟悉的路线。

Pengu 尝试把短语料转化为两组共同工作的生成条件：一组约束文字怎样写，另一组影响写作者怎样观察和判断。这里的“几百字”描述的是输入样本的规模，生成文章的篇幅由新任务另行设置。

## 两层风格模拟

### 第一层：机械语言特征

从文字表面提取或估计句长、断句与标点、段落长度、连接方式、词汇丰富程度，以及正式表达与口语表达的倾向。这一层为新文章提供句子节奏、段落组织和用词参考。

### 第二层：幕后写作者

让模型判断：在它自己的文本关联体系里，什么样的人最可能写出这些文字？

模型据此构造一套连贯的人物原型，可以包含大致年龄、性别、成长地域、家庭文化环境、教育背景、人格气质、价值判断、思考习惯和读者距离。这个原型进一步影响新文章的选材、观察角度、判断路径、情绪处理和表达方式。

这一步主动利用了大模型学到的社会身份与语言之间的关联，其中包括刻板印象。人物原型能同时带动多种表达选择，也可能补出样本没有充分支持的设定。Pengu 将它用于本次创作，不能据此认定现实作者的身份或人格。

幕后身份只参与生成。新文章应围绕新任务展开，不能把侧写中的年龄、家乡、家庭、学历或职业写成人物履历，也不能为了维持人设而编造第一人称经历。

## 样本文字与新文章材料分开使用

语料用于提供表达特征和创作性人物原型。新文章的主题、事实和参考材料由新任务另行给出，不能因为样本里出现了某个人物、事件或观点，就把它延续进新文章。

例如，你可以提供几段自己写过的影评作为表达参考，再以另一组材料写一篇科普短文。这个例子说明的是输入方式，不代表已经完成跨题材效果验证。具体输出仍需检查事实、语料复用和身份泄漏。

## 使用流程

1. **提供短语料。** 粘贴自己的、已获授权或经过脱敏的文字，也可以导入文本文件。语料是可选输入；要使用本文介绍的短语料风格模拟，应提供样本。
2. **查看并调整侧写。** 完整幕后写作者侧写可以查看、编辑、保存和加载。模型给出的设定可修改，用户保留最终判断。
3. **填写新任务。** 选择文体、目标字数，填写文章要求；按需补充特殊要求、目标读者、事实与参考资料。样本文字少，不意味着新任务可以缺少必要材料。
4. **从四份大纲里选方向。** 先比较文章准备怎样展开，再决定采用哪一份。
5. **比较六篇候选正文。** 查看不同版本与本轮相对评分，选择适合自己的稿件。分数只用于本轮候选比较，不能当成跨批次的绝对质量分。
6. **润色和导出。** 润色另存版本，保留原稿、原分与原排名，不重新评分。可以复制正文、下载 Markdown，或预览排版后导出 Word。

页面中的正文需要在关闭前导出，当前稿件不会在重新打开页面时自动恢复。

| 功能 | 当前方式 |
| --- | --- |
| 短语料风格引导 | 机械语言特征与幕后写作者共同参与生成 |

## 下载与启动

公开包通过本仓库的 [Releases](https://github.com/O0tter/Pengu/releases) 提供。下载 `Pengu-public-20260914.zip` 后完整解压，保留目录结构。

1. 准备本机 Python，建议使用 Python 3.12。
2. 双击包内 `setup_macos.command`，创建虚拟环境并安装锁定依赖。首次安装需要联网。
3. 双击同目录的 `StartPengu.app` 或 `start_pengu.command`，默认在浏览器打开 `http://127.0.0.1:5601/`。不要单独移动启动 App。
4. 打开页面顶部的 **API**，填写服务商地址、模型和 API Key。测试连接成功后，还需要点击“保存并启用”。
5. 使用完成后，通过页面中的“停止 Pengu”或 `stop_pengu.command` 结束运行。

也可以在解压后的目录执行：

```bash
zsh setup_macos.command
zsh start_pengu.command
```

这是源码启动包，不内置 Python 或模型，未进行 Apple 签名公证。AI 请求由你配置的服务商处理并计费。安装细节、模型设置及版本变更见压缩包内的 README 和 RELEASE_NOTES。

## 数据发送与本地保存

网页和应用运行在本机。调用外部模型时，相关文字仍会发送给所选 API 服务商：侧写分析需要部分语料样本，写作需要任务、参考资料和相关侧写，评分及润色需要处理中的文章。

API Key 优先保存于 macOS Keychain，公开版使用独立的 `pengu-public` 存储名称；也可以按包内 `.env.example` 配置本地环境文件。API 配置和侧写会产生本地记录，使用后不要把这些记录随源码再次分发。详细范围见包内 PRIVACY。

## 方法边界

样本少时，模型更容易调用宽泛的人物原型，也可能把题材影响误当成作者习惯。幕后身份只作为创作条件，不能用于判断现实作者是谁。

模型输出还会受到题目、参考材料和模型本身的影响。当前没有足够公开对照结果支持“稳定还原个人文风”或“不同模型效果一致”等结论。使用者仍需检查生成文章的事实、观点、表达和来源；项目不承诺任何检测器的判定结果。
